# Neo Planner

This project is sporadically maintained! Do not expect regular updates. For regular updates, please navigate to [Neo Tinkers'](https://github.com/vancevoj/neotinkers) and [Neo Mantle](https://github.com/vancevoj/neomantle).

This is **Minecraft 1.21.1 NeoForge** port of **Tinkers' Planner** by Tiffit & SpikyStars, an add-on for Tinkers' Construct.

Neo Planner is a **client-side** mod. It adds an *Open Planner* button to the Tinker Station & Tinkers' Anvil that lets you try out different material and modifier combinations on a tool before actually building it. It **requires [Neo Tinkers'](https://github.com/vancevoj/neotinkers)** (and, through it, Neo Mantle).

Full credit for the mod goes to Tiffit & SpikyStars, and to SlimeKnights for Tinkers' Construct itself. I take no credit for any of the original work. This project is in no way endorsed by or affiliated with the original authors or SlimeKnights.
